1. The Problem Solved in Week 9

Before Week 9, your AWS Lambda function lived only in the AWS Console web editor. This created three major risks:

  • Code Drift: Code modified in the browser had no git commit history, no PR review, and could easily be lost.
  • Credential Exposure: Developing in multiple environments often tempts developers to hardcode API tokens or secrets.
  • Manual Friction: Every code change required opening AWS Lambda, zipping files on your laptop, or copying and pasting into the AWS web editor.

The Week 9 Solution: We connected your actual 3,778-line production serverless engine to git, configured GitHub Actions CI/CD with secure repository secrets, and established an automated pipeline where any git push deploys cleanly to AWS Lambda in us-east-2.
