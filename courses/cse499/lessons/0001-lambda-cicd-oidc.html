2. Step-by-Step AWS Setup (5–10 Minutes)

You need to create a dedicated IAM user in AWS with permission to update your Lambda function.

A Log into the AWS Console

  1. Go to console.aws.amazon.com and sign in.
  2. Verify your region is set to US East (Ohio) us-east-2 in the top-right header (matches your API Gateway 1s8yydgkbk.execute-api.us-east-2.amazonaws.com).

B Find Your Lambda Function Name

  1. Open the AWS Lambda Console.
  2. Find your weekly report function in the list (e.g. sunny-weekly-fleet-report, weeklyFleetReport, or similar).
  3. Copy the exact Function name. You will need this for GitHub Secrets.

C Create an IAM User for GitHub Actions

  1. In the top search bar, type IAM and click into the IAM dashboard.
  2. In the left sidebar, click Users → click Create user.
  3. User name: github-actions-sunny-deployer. (Do NOT check console access). Click Next.
  4. Under Permissions options, choose Attach policies directly.
  5. Click Create policy (opens a new tab), switch to the JSON tab, and paste:
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "lambda:UpdateFunctionCode",
        "lambda:GetFunction",
        "lambda:GetFunctionConfiguration"
      ],
      "Resource": "arn:aws:lambda:us-east-2:*:function:*"
    }
  ]
}
  1. Click Next → Policy name: SunnyLambdaDeployPolicy → click Create policy.
  2. Return to your User creation tab, refresh the policy list, select SunnyLambdaDeployPolicy, and click Next → Create user.

D Generate Access Keys

  1. Click into the user github-actions-sunny-deployer you just created.
  2. Click the Security credentials tab → scroll to Access keys → click Create access key.
  3. Select Command Line Interface (CLI) → check the confirmation box → click Next → Create access key.
  4. Keep this window open! Copy:
    • Access key ID (starts with AKIA...)
    • Secret access key (long random string)

3. Add Secrets to Your GitHub Repository

Now give GitHub Actions permission to use these credentials.

  1. Go to your GitHub repository: github.com/aheiner2001/sunny.
  2. Click Settings (gear icon in repository header) → in left menu, click Secrets and variables → Actions.
  3. Click New repository secret and add the following 3 secrets:
Secret Name Value
AWS_ACCESS_KEY_ID Your Access Key from Step 2D (starts with AKIA...)
AWS_SECRET_ACCESS_KEY Your Secret Access Key from Step 2D
AWS_LAMBDA_FUNCTION_NAME Your exact Lambda function name from Step 2B

4. Testing & Verification: How You Know Week 9 Is Complete

Once your secrets are added, verify the end-to-end pipeline:

  1. Go to github.com/aheiner2001/sunny/actions.
  2. Click the Deploy Lambda to AWS workflow in the left list.
  3. Click Run workflow → select branch main (or feat/senior-project-cloud-and-teaching) → click green Run workflow button.
  4. Watch the job execute:
    • ✓ Validate Lambda Syntax
    • ✓ Package Deployment Archive (dist/index.mjs with luxon bundled)
    • ✓ Authenticate to AWS
    • ✓ Deploy to AWS Lambda
  5. Check the AWS Lambda console: the Last modified timestamp on your function will update to right now!
