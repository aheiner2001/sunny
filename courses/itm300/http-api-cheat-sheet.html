HTTP API Fundamentals & Node.js Routing

Status Codes in Reporting APIs

  • 200 OK: Request succeeded; body contains the requested report payload.
  • 400 Bad Request: Missing or malformed input (e.g., invalid weekStart format).
  • 401 Unauthorized: Missing or invalid authentication token (Who are you?).
  • 403 Forbidden: Authenticated user lacks permission (e.g., employee attempting to read manager reports).
  • 404 Not Found: Route or resource does not exist.

Parsing URL Queries in Native Node.js

import http from 'node:http';

const server = http.createServer((req, res) => {
  // Construct a WHATWG URL instance using a dummy host
  const parsedUrl = new URL(req.url, `http://${req.headers.host || 'localhost'}`);
  const pathname = parsedUrl.pathname;
  const weekStart = parsedUrl.searchParams.get('weekStart');

  if (req.method === 'GET' && pathname === '/reports/weekly/preview') {
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ weekStart }));
    return;
  }

  res.writeHead(404, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ error: 'Not Found' }));
});
