Connecting the UI "Preview Report" Button to the API

The full round-trip: from React click, to Lambda preview, to rendering the live modal.

Yes! That is Exactly How It Works

Your intuition is 100% spot-on:

  1. A manager clicks a "Preview Weekly Report" button on the Reports page.
  2. The React app calls the HTTP API endpoint (or our local dev server).
  3. The Lambda runs in preview mode (never sending an email).
  4. The Lambda returns the calculated stats as JSON.
  5. The React app displays a popup/modal showing the manager the exact report numbers!

Step 1: The Lambda's API Gateway Adapter

In lamdba/index.mjs, we support both direct invocations and API Gateway HTTP requests:

// Detect if invoked via HTTP API Gateway
const isHttpApi = Boolean(event.rawPath || event.requestContext?.http);

// Return HTTP-wrapped response if called via API Gateway
if (isHttpApi) {
  return {
    statusCode: 200,
    headers: {
      "Content-Type": "application/json",
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "GET,OPTIONS"
    },
    body: JSON.stringify(previewResult)
  };
}

Step 2: The Next.js / React Frontend Button

On the Reports page (src/app/reports/page.tsx), we add the action button:

<button
  onClick={handleFetchPreview}
  className="btn btn-secondary cluster gap-2">
  <Sparkles className="w-4 h-4 text-amber-500" />
  <span>Preview Live Lambda Report</span>
</button>

Step 3: The Preview Modal

When the data returns, a clean popup renders:

  • Report Period: (e.g., Nov 2 - Nov 8, Denver Time)
  • Timesheet Hours: Approved vs Pending hours
  • Fleet Setup Gaps: Vehicles requiring attention
  • Status: Clear confirmation that "No email was sent (Preview Mode)"
