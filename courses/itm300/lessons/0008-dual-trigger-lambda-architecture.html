One Lambda, Two Doors: Cron Schedule vs. Manager Live Preview

How a single Lambda function sends scheduled weekly emails AND serves live on-demand API previews without breaking anything.

Your Core Question Answered: Does It Still Send the Weekly Email?

YES! 100% Yes. The weekly email scheduler continues to run untouched.

Think of your Lambda function as a single kitchen with two different doors: 


                      ┌────────────────────────────────────────┐
                      │          YOUR LAMBDA FUNCTION          │
                      │           (The Core Engine)            │
                      └────────────────────────────────────────┘
                                    ▲            ▲
                                    │            │
            DOOR 1: Scheduled Cron  │            │  DOOR 2: Manager API
         (Automatic Weekly Service) │            │  (Live On-Demand Preview)
                                    │            │
          Every Sunday at Midnight  │            │  Whenever a manager clicks
            • dryRun = false        │            │    "Preview Today's Report"
            • Computes past week    │            │  • dryRun = true (NEVER emails!)
            • Sends emails via SES  │            │  • Can look at current week/day
                                    │            │  • Returns instant HTTP JSON

How the Code Knows Which Door Opened

The Lambda handler inspects the event object passed to it. It’s like checking who knocked on the door: 

export async function handler(event = {}) {
  // Did API Gateway knock? (HTTP request)
  const isHttpApi = Boolean(event.rawPath || event.requestContext?.http);

  if (isHttpApi) {
    // 🚪 DOOR 2: A Manager is asking via the API!
    // Force dryRun: true so we NEVER accidentally send an email while testing
    // Can preview "current" week or today's live data
    const previewData = buildLivePreview(event);
    return {
      statusCode: 200,
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(previewData)
    };
  }

  // 🚪 DOOR 1: The AWS Cron Scheduler knocked! (Standard weekly run)
  // Runs normal email generation and delivers via SES
  return runScheduledWeeklyEmailDelivery();
}

Why This Is the Industry Best Practice

  • Zero Code Duplication: The math for shifts, service gaps, and inspection warnings is written once and shared by both triggers.
  • Failsafe Email Protection: Whenever accessed through HTTP API, dryRun is hard-coded to true. Even if a manager tests the endpoint 50 times an hour, zero emails are ever sent.
  • Live Mid-Week Intelligence: A manager doesn't have to wait until Sunday midnight to see if a vehicle is overdue for an oil change or an employee has unapproved hours—they can see it live right now.

Self-Check

Question: If you add HTTP API Gateway preview capability to the Lambda, does it disrupt or stop the weekly scheduled email from running?

Answer: No. The cron job continues to trigger on schedule and send SES emails just like before. The API simply provides a read-only preview window into the exact same data engine.
