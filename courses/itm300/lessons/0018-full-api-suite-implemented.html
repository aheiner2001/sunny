Lesson 0018

Full API Suite: Week Toggling, Draft Emails, & Multi-Routing

All three capabilities are now live on your branch and open in your editor.

1. Interactive Week Toggling (Live in UI!)

The preview modal now features a [ Current Week ] / [ Previous Week ] segmented pill in the top header.

  • Clicking Previous Week calls ?week=previous to view closed payroll numbers.
  • Clicking Current Week calls ?week=current to view live hours accumulating today.

2. On-Demand Draft Email Dispatch (POST API)

Inside the preview dialog, managers can now type their email address and click "Send Draft SES Email".

  • Sends an HTTP POST request with { email, week }.
  • Bypasses the regular recipient list to send a safe one-off proof to the specified manager only.

3. Multi-Route Training Gaps (GET /training/gaps)

Added routing in lamdba/index.mjs for /training/gaps.

In your AWS API Gateway console, you can optionally add a route for GET /training/gaps pointing to the same Lambda function to activate it.

What to Copy to AWS Lambda

The updated lamdba/index.mjs is already open in your editor. Select all (Cmd+A), copy, paste into the AWS Lambda Code tab, and click Deploy!
