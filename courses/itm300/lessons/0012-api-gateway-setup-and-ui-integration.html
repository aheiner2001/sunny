Part 1: Your Lambda is Updated and Ready!

The Lambda code in lamdba/index.mjs has now been updated and opened in your editor.

  • It now automatically detects HTTP requests from AWS API Gateway.
  • It automatically prevents emails during previews (dryRun = true).
  • It returns standard HTTP 200 OK with CORS headers.

Part 2: Setting Up the AWS API Gateway (5 Simple Steps)

In the AWS Console:

  1. Go to API Gateway and click Create API.
  2. Under HTTP API (fast and free tier), click Build.
  3. Add an Integration:
    • Choose Lambda.
    • Select your existing Lambda function name from the dropdown.
    • API name: sunny-fleet-api.
  4. Configure Routes:
    • Method: GET
    • Resource path: /reports/weekly/preview
    • Integration: select your Lambda.
  5. Click Next → Next → Create! AWS will give you an Invoke URL (e.g. https://abc123xyz.execute-api.us-west-2.amazonaws.com).
