Lesson 0007

Exposing Report Previews via Manager API Gateway

Adapting your Lambda into a live, interactive API where managers can preview reports on-demand.

The Core Concept: Scheduled Job vs. On-Demand API

Currently, AWS Lambda can run in two ways:

Trigger How It Runs Output
Cron / EventBridge Runs automatically once a week Sends weekly emails to fleet managers
API Gateway (HTTP API) Runs when a manager clicks "Preview Report" in the app Returns immediate JSON with { dryRun: true }

How the Handler Adapts for API Gateway

When an API Gateway calls your Lambda handler, it provides an event with query parameters and headers:

// Manager calls: GET /reports/weekly/preview?week=current
export async function handler(event = {}) {
  // 1. Detect if this came from HTTP API Gateway
  const isHttpApi = Boolean(event.rawPath || event.requestContext?.http);

  // 2. Extract manager parameters
  const query = event.queryStringParameters || {};
  const mode = query.week || "previous"; // current or previous week

  // 3. Set dryRun = true so it NEVER sends actual emails during preview!
  const dryRun = query.send !== "true";

  // 4. Return standard HTTP API response format
  return {
    statusCode: 200,
    headers: {
      "Content-Type": "application/json",
      "Access-Control-Allow-Origin": "*"
    },
    body: JSON.stringify({
      mode: "preview",
      period: report.period,
      summary: report.summary,
      gaps: analytics.setupGaps,
      timesheets: analytics.timesheets
    })
  };
}

What a Manager Can Do Through the API

  • Preview Before Sending: Check current week numbers before the scheduled Sunday email fires.
  • Inspect Setup Gaps: Spot vehicles missing safety setups or overdue maintenance.
  • Check Shift Totals: Validate approved vs. pending driver hours.

Check Your Understanding

Question: Why do we enforce dryRun: true when handling requests from the preview API endpoint?

Answer: To guarantee that reviewing report data or testing numbers in the dashboard never accidentally triggers SES email dispatches to managers.
