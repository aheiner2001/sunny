1. Input Validation: Handling Bad Requests (HTTP 400)

In REST APIs, if a client provides a missing parameter or malformed date, the server must reject it immediately with an HTTP 400 Bad Request status code before touching data or doing math.

Postel's Law vs API Security: "Be conservative in what you send, be liberal in what you accept." In modern security, however, input validation must be strict: never allow ambiguous date strings to propagate into financial or timesheet records. 
import { DateTime } from 'luxon';

const weekStartStr = parsedUrl.searchParams.get('weekStart');
if (!weekStartStr) {
  res.writeHead(400, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ error: "Missing required query parameter 'weekStart'" }));
  return;
}

const dt = DateTime.fromISO(weekStartStr, { zone: 'America/Denver' });
if (!dt.isValid) {
  res.writeHead(400, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ error: "Invalid date format for 'weekStart'. Expected YYYY-MM-DD." }));
  return;
}

2. Week Boundaries in America/Denver

Sunny Fleet operates in America/Denver. In November 2026, Daylight Saving Time ended on Sunday, November 1 at 2:00 AM (switching from MDT UTC-6 to MST UTC-7).

For weekStart=2026-11-02 (a Monday):

  • Week Start: Monday, Nov 2, 2026 at 00:00:00 Denver → 2026-11-02T07:00:00.000Z
  • Week End: Sunday, Nov 8, 2026 at 23:59:59.999 Denver → 2026-11-09T06:59:59.999Z

3. The Boundary Test Case

What happens if an employee works a shift on Sunday evening, Nov 1 that ends right at midnight as Monday begins?

  • Shift A: Ends at 2026-11-02T06:59:59.000Z → Belongs to previous week.
  • Shift B: Starts at 2026-11-02T07:00:00.000Z → Belongs to this week.
